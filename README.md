# Experiment 7 — Firestore Data Persistence (UI Demonstration)

A standalone Flutter app demonstrating how an employee record entry/list screen could look when backed by Cloud Firestore. **This is a UI-only simulation:** no Firebase project, account, or network connection is used, and sample/added records reset when the app closes.

## Run

From this folder:

```sh
flutter pub get
flutter run -d windows
# or: flutter run -d chrome
```
